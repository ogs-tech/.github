## Documentação

O hub [`docs/`](docs/) documenta cada serviço e produto ativo, organizado pelo **guarda-chuva de
marca** (OGS Partners · OGS Studio · OGS Engine), com os quadrantes [Diátaxis](https://diataxis.fr)
dentro de cada produto. Comece por [`docs/README.pt-BR.md`](docs/README.pt-BR.md) ou vá direto à
[arquitetura de marca](docs/explanation/brand-architecture.md). Projetos legados não são documentados.
