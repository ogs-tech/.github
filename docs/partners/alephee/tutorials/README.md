# Alephee — Tutorials

> *Learning-oriented.* End-to-end lessons that take a newcomer from zero to a working setup.
> A tutorial teaches by doing — it is a guided experience, not a task recipe (those live in
> [How-to](../how-to/)).

## Planned tutorials *(stubs — to be written)*

- [ ] **Run Alephee locally** — clone the six repos, bring up Kong + MongoDB + Redis via
  `core-services/dev-compose.yaml`, start `core-services` and `ui-core`, see a catalog render.
- [ ] **Build your first vendor adapter** — scaffold an adapter from `@alephee/vendors-adapter-sdk`,
  implement the Categories + Listing contracts against a mock vendor.
- [ ] **Publish a product end to end** — from `ui-core` through `core-services` to a vendor adapter.

> Template for each tutorial: *Goal → Prerequisites → Numbered steps (each with expected output)
> → "What you learned" → Next steps.* Keep it runnable start to finish.

Existing material to draw from: `alephee/ui-core/docs/` (already has a `tutorials/` section).
