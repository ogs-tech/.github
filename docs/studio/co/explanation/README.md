# OGS Studio Co. — Explanation

> *Understanding-oriented.* Why a done-for-you service, and how it fits the umbrella.

## Why done-for-you

Many Brazilian SMBs need a professional web/content presence but have no interest in running CMS
infrastructure, deployments, or upgrades. The Open Source and Cloud doors of the Press still
assume someone technical operates the site. **Co. removes that assumption**: OGS operates the
Press for the client end to end.

## How it uses the Press

Co. is not a separate technology — it is a **service wrapper around the [Press](../../../engine/press/)**.
The same CMS core that developers self-host and agencies buy as Cloud is what Co. operates on
behalf of SMB clients. This is why the brand model calls the Press a platform with **three doors**:
the third door is simply "we run it for you."

## Segments

- **Empresas (primary):** the core SMB market — the main revenue line for Studio.
- **Influencers (niche):** creators handled as a company; this niche is where
  [Royale IQ](../../royale-iq/) sits (pro bono, powered by Agent AI).
