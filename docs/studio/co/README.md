# OGS Studio Co.

<!-- nav -->
[Docs](../../) › [OGS Studio](../) › Co.

> **Done-for-you IT services** for Brazilian SMBs — operates the [Press](../press/) on clients' behalf.

Studio Co. is the managed-services arm: instead of selling software for clients to run, OGS runs
it for them. It is the **Co.** door of the Press, and the primary revenue segment of OGS Studio.

- **Brand:** OGS Studio
- **Nature:** service offering (no dedicated code repository — it operates existing products)

## Segments

| Segment | Audience | Note |
|---|---|---|
| **Empresas** *(primary)* | Brazilian SMBs | the main revenue segment |
| **Influencers** *(niche)* | creators treated as a company | includes [Royale IQ](../royale-iq/) |
