# Studio Press Cloud

<!-- nav -->
[Docs](../../) › [OGS Studio](../) › Press Cloud

> The **managed, multi-tenant Cloud** form of [Press](../press/) — packaged and sold as a SaaS · OGS Studio.

Studio Press Cloud (a.k.a. **Next in Site Cloud**) is the hosted form of the
[Press CMS core](../../engine/press/). It lets small Brazilian digital agencies host and manage
**5–50 client sites** with consolidated billing, a portfolio dashboard, and AWS-managed deployments.

- **Brand:** OGS Studio
- **Engine:** [Press (CMS core)](../../engine/press/) — `internal/studio-press-cli`
- **Repository:** [`ogs-tech/studio-press-cloud`](https://github.com/ogs-tech/studio-press-cloud) *(discovery)*
- **Within Press:** the **Cloud door** of [Studio Press](../press/) (alongside Open Source and Co.)
