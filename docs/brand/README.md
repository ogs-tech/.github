> **Seu negócio. Além.** · *Future Ready.* — the OGS Tech brand identity.

This section holds the **brand identity** of OGS Tech (Odenir Gomes Soluções), distilled from the
**Brand Manual** (*Manual de Marca*), V1.0 · 2026. It complements the
[Brand Architecture](../explanation/brand-architecture.md) — which explains the *business* umbrella
(Partners · Studio · Engine) — by covering the *identity*: who the company is and how the mark looks.
