> *Understanding-oriented.* How the three brands feed each other.

The three brands are not independent silos — they form a value chain:

```
   OGS Engine  ──builds──►  OGS Studio  ──sells──►  customers
   (machine room)           (packages)
        │
        └──executes──►  OGS Partners  ──delivers──►  bespoke clients
                        (premium)        (may use the Press)
```

## The three rules

1. **Engine is the machine room.** It builds the core technology: the **Press** (CMS core) and
   **Agent AI** (AI core). Nothing is sold from Engine directly.

2. **Studio packages and sells; Partners does the premium.** Studio turns Engine's output into
   repeatable products. Partners delivers bespoke, high-margin engagements — executed by Engine,
   and its deliverables **may use the Press**.

3. **The Press has three doors**, chosen by who is using it:
   - **Open Source** → developers (free, self-host)
   - **Cloud** → agencies (managed, paid)
   - **Co.** → SMBs (done-for-you; Studio Co. operates the Press for them)

## Engines becoming products

| Engine (built in OGS Engine) | Product (sold by OGS Studio) |
|---|---|
| Press — CMS core | OGS Studio Press |
| Agent AI — AI core | Royale IQ |

Superset AI is the exception: it stays internal — a desktop tool that helps the OGS team work
with Claude and its adaptations.
